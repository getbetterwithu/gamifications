## 개정 원칙 (v1 → v2)

1. **긴장·위기**: 의회 최후통첩(폭풍에 토대 유실 시 공사권 박탈), 사보타주 2건, "사람이 깔린다" 급 실질 위협
2. **다이달로스 = 보스**: 1장부터 협박 쪽지 "D" → 사보타주 → 9장 1:1 대결(동시에 푸는 레이스 연출) → 13장 재등장. 패배해도 승복 안 함. 동기 = 4단원 엔딩에서 피타고라스가 폴리곤에게 약속한 "이름"에 대한 질투
3. **미스터리**: "빈 칸을 누가 왜 비워뒀나" 떡밥을 1·6·7·10장에 깔고 12장에서 회수 (탈레스 = 테론의 옛 스승, 4단원 엔딩의 창고·황금 비례판 떡밥 회수)
4. **중2 톤**: 나레이션 최소화, 대사 짧게, 티키타카·도발·리액션 위주. 문제 정답 = 상대가 데미지 입는 연출
5. **이리스 썸 라인**: S2(첫 재회) → S4(목격·놀림) → S9 직전(걱정) → S11(투샷 메인) → S14·15(이름 불러주기). 수위는 "어? 뭐지 이 분위기" 선까지만
