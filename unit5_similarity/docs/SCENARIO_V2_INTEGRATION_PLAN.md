## 3. 자문 39개 처리 현황

**이미 현 scenario.js에 반영됨** (재확인만):
- 신전 단계 시각화 — temple_site0~5 + storm/sunset mood + changeBg 색보정 ✅

**v2 각색이 자동 해결** (씬 구조에 내장):
- 초반 후크 없음 → S1 D쪽지·S2 최후통첩 ✅
- 선택지 0개 → S9·S11 choice (현 1개 + 1개 추가 = 2개) ✅
- 주인공 수동성 → S12 통찰 주체를 폴리곤으로 ✅
- 단조 배경(7씬 동일 yard) → 배경 다변화 ✅

**신규로 직접 반영 필요** (이번 작업 핵심):
- 정답 미리말하기 제거 — S4·S5 해당 라인(주인공이 16:25, 27:64 선언 → 의문만 남기고 결론은 onCorrect NPC 대사로)
- onWrong 힌트 6곳(BRICK·GLASS·CLAY·MEASURE·SHADOW·GOLDEN) 정답풀이 통째 공개 → 방향만 환기, 떠먹이기는 problems.js `hints[]`로 위임

**함께 대기 중인 게임 기능 수정** (scenario와 별개, 같은 묶음 처리):
- 테론 잔상 제거 / 엔딩 "다시 시작" 버튼 / 나레이션 중앙카드 / 문제창 위로 배치

## 4. 작업 순서 (WORK_PLAN 직렬 골격 위에)

1. **problems.js** — onWrong 힌트를 `hints[]` 단계 힌트로 이관(자문#2) → 6문제
2. **scenario.js 재작성** — v2 15씬 구조 + 충돌 3건 적용 + 정답 미리말하기 제거(자문#1)
3. **엔진 기능 4건** — 테론 잔상·다시시작 버튼·중앙카드·문제창 위치
4. **storyboard.html로 검수** — 씬 흐름·대사·문제·정답 한눈에 확인
5. **크롬 no-cache 실행 테스트** → 배포

핵심 직렬: 1 → 2 → 4. 엔진 기능(3)은 병행 가능.
